Struttura del sistema

Il progetto ha un solo obiettivo: ottenere un valore numerico da un albero di regressione. La GUI mostra il modello; il client testuale lo usa per predire.

Confine funzionale. La GUI accetta sia file locali sia tabelle remote. La predizione interattiva resta nel client testuale. Senza server e database, la GUI può comunque lavorare sui file .dat.

Responsabilità

ComponenteFaNon fa

mapServer.jarlegge il database, apprende o carica un albero, salva l’archivio e serve più sessioninon presenta un’interfaccia utente
mapClient.jarcomanda il server da terminale e guida la scelta dei rami fino alla predizionenon disegna il modello

Comunicazione remota

Il server apre un thread per client e usa stream di oggetti su TCP. I comandi principali sono: carica dati, apprendi, carica archivio e predici.

Per visualizzare un albero remoto, la GUI percorre il protocollo di predizione e ricostruisce un VisualTree.

Apprendimento

Ogni foglia restituisce la media del target nella propria partizione. Gli split sono scelti minimizzando l’errore quadratico.

ŷS = (1 / |S|) · Σi∈S yi
SSE(S) = Σi∈S (yi − ŷS)²

Nel codice il campo si chiama variance, ma contiene la somma degli errori quadratici (SSE), non la varianza normalizzata.

1. CaricaLegge schema, attributi e target.
2. ConfrontaCalcola il costo degli split validi.
3. SceglieMinimizza la somma delle SSE dei figli.
4. RipeteCrea sotto-alberi o una foglia con la media.
Arresto. Una partizione diventa foglia se contiene al massimo il 10% degli esempi iniziali, calcolato con divisione intera, oppure se lo split non genera più di un ramo utile.

Attenzione. Lo script SQL ricrea il database MapDB. Il Connector/J deve restare accanto a mapServer.jar. Il server usa per impostazione corrente localhost:3306, utente MapUser.

Limiti principali

IntegrazioneMancano test automatici con database reale, socket end-to-end e più client concorrenti.
Configurazione e reteCredenziali e database sono fissi; il protocollo non usa TLS né autenticazione.
GUI sincronaTraining e rete lavorano sull’EDT. Dataset o alberi grandi possono bloccare la finestra.
DistribuzioneGli archivi usano la serializzazione Java e il sorgente del server non è incluso nel repository.
Valutazione. Il progetto realizza il flusso completo: acquisizione dei dati, apprendimento, visualizzazione e predizione. Le priorità successive sono test end-to-end, configurazione esterna e lavoro asincrono nella GUI.
