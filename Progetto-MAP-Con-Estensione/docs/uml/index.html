Diagrammi UML — Progetto MAP con estensione

16 diagrammi: 11 delle classi, 4 dei package e una panoramica architetturale. Alla GUI sono dedicati soltanto un diagramma delle classi e uno dei package.

Le viste dei package e la panoramica usano flowchart Mermaid. La raccolta documenta i 38 file Java applicativi della base e le 8 classi dell’estensione Swing; i test sono esclusi.

Apri gli SVG per leggere i dettagli con lo zoom; usa i PNG nei documenti e i file Mermaid per modificare i diagrammi. La galleria e le immagini sono consultabili offline, senza JavaScript o servizi esterni.

Visibilità: + public, - private, # protected, ~ package-private. Sottolineatura: statico; corsivo: metodo astratto. Triangolo: ereditarietà o realizzazione; rombo pieno: composizione; freccia continua: associazione; freccia tratteggiata: dipendenza.

Server e applicazione src contengono classi omonime ma distinte. La GUI include soltanto la base locale da project/src/src/ e comunica con il server via TCP. I gruppi interni della GUI non sono sottopackage.
